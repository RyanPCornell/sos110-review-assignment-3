# SOS 110 · In-Class Review Assignment 3: The Los Angeles River as a System

A five-slide web deck for In-Class Review Assignment 3.

**Live:** https://ryanpcornell.github.io/sos110-review-assignment-3/

1. **Title**: a hand-drawn cross-section of the river, concrete channel beside a restored river.
2. **Before You Build**: the PBS *Earth Focus* episode "Reimagining the Los Angeles River" (embedded; it loads only
   when the slide opens), what to watch for, and the ArcGIS StoryMap reading.
3. **Six Questions, Three Systems**: the socio-economic, ecological and technical questions.
4. **What Your Poster Needs**: the flowchart symbols, the four system-dynamics ideas, the include list, and help
   with Save as PDF on Windows, Mac, Chromebook and Firefox.
5. **★ Systems Poster Builder**: three system lanes inside a system boundary, the sheet's flowchart symbols, plain and
   + / − arrows, engineered-era vs restoration tags, automatic feedback-loop detection, text boxes for the six
   answers and a summary, browser autosave, Save / Open a `.poster.json` file, and a landscape **Save as PDF** poster.

The builder also runs on its own at https://ryanpcornell.github.io/sos110-systems-poster-builder/ (same browser
autosave, so work started on one opens on the other).

Add `?host` to the deck's URL for the instructor copy, which shows the day's in-class code at the top of every slide
(click it for a full-screen version). Students type it into the builder, which checks it and prints it on the PDF.

Everything is self-contained: no build step, no dependencies. The only external requests are Google Fonts and, on
slide 2, the PBS player. Nothing students make is uploaded anywhere.

Built from `_deck-builder/review3_assignment.py` + `_deck-builder/review3_poster_builder.py` (not in this repo).
